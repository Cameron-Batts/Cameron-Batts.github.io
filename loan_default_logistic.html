```{r preparation}
loans <- readRDS("Data/LoanData.rds")
stopifnot(all(loans$isLoanDefault %in% c(0, 1)))
# Fixed data-quality rule; no outcomes are used to choose exclusions.
loans <- loans[!is.na(loans$incomeAnnual) & loans$incomeAnnual <= 2500000, ]
loans$isLoanDefault <- factor(loans$isLoanDefault, levels = c(0, 1))
set.seed(2020)
# Split within class before learning imputation values or resampling.
test_rows <- unlist(lapply(split(seq_len(nrow(loans)), loans$isLoanDefault),
                          function(rows) sample(rows, floor(length(rows) / 3))))
train <- loans[-test_rows, ]
test <- loans[test_rows, ]
stopifnot(length(intersect(rownames(train), rownames(test))) == 0)
for (v in c("interestRate", "employmentYears")) {
  fill <- median(train[[v]], na.rm = TRUE)
  stopifnot(is.finite(fill))
  train[[paste0(v, "_missing")]] <- as.integer(is.na(train[[v]]))
  test[[paste0(v, "_missing")]] <- as.integer(is.na(test[[v]]))
  train[[v]][is.na(train[[v]])] <- fill
  test[[v]][is.na(test[[v]])] <- fill
}
stopifnot(!anyNA(train), !anyNA(test))
metrics <- function(truth, predicted) {
  cm <- table(actual = factor(truth, levels = c(0, 1)),
              predicted = factor(predicted, levels = c(0, 1)))
  tn <- cm[1,1]; fp <- cm[1,2]; fn <- cm[2,1]; tp <- cm[2,2]
  ratio <- function(a,b) if (b == 0) NA_real_ else a/b
  print(cm)
  c(accuracy = (tn+tp)/sum(cm), precision_default = ratio(tp,tp+fp),
    recall_default = ratio(tp,tp+fn), specificity = ratio(tn,tn+fp),
    balanced_accuracy = mean(c(ratio(tp,tp+fn),ratio(tn,tn+fp))))
}
```
## Fit logistic models on identical training rows
This source is a newly reconstructed workflow informed by the archived report, not a recovered original notebook. Training-only median imputation replaces historical complete-case deletion. New outputs will therefore differ from the PDF.

```{r fit-logistic}
full <- glm(isLoanDefault ~ ., data = train, family = binomial())
top5 <- glm(isLoanDefault ~ incomeAnnual + creditGrade + interestRate +
              employmentYears + loanAmount, data = train, family = binomial())
top3 <- glm(isLoanDefault ~ incomeAnnual + creditGrade + interestRate,
            data = train, family = binomial())
stopifnot(nobs(full) == nobs(top5), nobs(top5) == nobs(top3))
AIC(full, top5, top3)
summary(full)
```

## Evaluate prespecified thresholds
The full model is used for all threshold comparisons. The thresholds are fixed examples, not selected using test labels. A final operational threshold would require separate validation and explicit cost assumptions.

```{r evaluate}
probability <- predict(full, newdata = test, type = "response")
stopifnot(all(is.finite(probability)))
for (threshold in c(0.1, 0.2, 0.5)) {
  cat("\nThreshold:", threshold, "\n")
  print(metrics(test$isLoanDefault, as.integer(probability >= threshold)))
}
metrics(test$isLoanDefault, rep("0", nrow(test)))
mean((probability - as.integer(test$isLoanDefault == "1"))^2)
```
All default-recall calculations use class 1 as positive. Odds ratios describe conditional associations rather than causal effects or direct changes in probability. AIC comparison is meaningful here because all three models use identical observations; the original PDF compared some fits with different row counts.
