Loan Default Classification with Cost-Sensitive Trees

Cameron Batts

Problem

Examine class imbalance, classification-tree pruning and explicit false-negative cost assumptions.

Approach

Split by class before preprocessing, learn median fills on training rows, resample only training observations to a 2:1 nondefault/default ratio, explicitly fit a classification tree and prune at a fixed cp=0.002. Evaluate class-1 recall against an all-nondefault baseline.

Reported results

The bundled dataset has 29,092 records, including 3,227 defaults (11.09%). The archived analysis illustrates a root-only initial tree and later tree structures, but reports no held-out classification metrics. Improved default detection has not been established.

Limitations and corrections

Historical resampling used the full dataset after creating a split, and later rpart fits omitted method="class" while the response was numeric. This revision fixes both issues. Pruning uses the original fixed cp rather than claiming CV selection. Resampling changes prevalence and the 10:1 loss is illustrative. Training imputation precedes internal rpart CV, so its scores are not fully fold-isolated; final assessment uses the untouched test split.

```{r preparation}
loans <- readRDS("Data/LoanData.rds")
stopifnot(all(loans$isLoanDefault %in% c(0, 1)))
# Fixed data-quality rule; no outcomes are used to choose exclusions.
loans <- loans[!is.na(loans$incomeAnnual) & loans$incomeAnnual <= 2500000, ]
loans$isLoanDefault <- factor(loans$isLoanDefault, levels = c(0, 1))
set.seed(2020)
# Split within class before learning imputation values or resampling.
test_rows <- unlist(lapply(split(seq_len(nrow(loans)), loans$isLoanDefault),
                          function(rows) sample(rows, floor(length(rows) / 3))))
train <- loans[-test_rows, ]
test <- loans[test_rows, ]
stopifnot(length(intersect(rownames(train), rownames(test))) == 0)
for (v in c("interestRate", "employmentYears")) {
  fill <- median(train[[v]], na.rm = TRUE)
  stopifnot(is.finite(fill))
  train[[paste0(v, "_missing")]] <- as.integer(is.na(train[[v]]))
  test[[paste0(v, "_missing")]] <- as.integer(is.na(test[[v]]))
  train[[v]][is.na(train[[v]])] <- fill
  test[[v]][is.na(test[[v]])] <- fill
}
stopifnot(!anyNA(train), !anyNA(test))
metrics <- function(truth, predicted) {
  cm <- table(actual = factor(truth, levels = c(0, 1)),
              predicted = factor(predicted, levels = c(0, 1)))
  tn <- cm[1,1]; fp <- cm[1,2]; fn <- cm[2,1]; tp <- cm[2,2]
  ratio <- function(a,b) if (b == 0) NA_real_ else a/b
  print(cm)
  c(accuracy = (tn+tp)/sum(cm), precision_default = ratio(tp,tp+fp),
    recall_default = ratio(tp,tp+fn), specificity = ratio(tn,tn+fp),
    balanced_accuracy = mean(c(ratio(tp,tp+fn),ratio(tn,tn+fp))))
}
```
## Fit a classification tree
The original source resampled from the full dataset after splitting and omitted `method="class"` in later fits with a numeric target. This revision resamples only training rows and uses an explicit classification target. Test results from this revision have not been generated here.

```{r fit-tree}
library(rpart)
default_rows <- which(train$isLoanDefault == "1")
nondefault_rows <- which(train$isLoanDefault == "0")
set.seed(2020)
keep <- c(default_rows, sample(nondefault_rows,
                               min(length(nondefault_rows), 2 * length(default_rows))))
resampled <- train[keep, ]
# Row = actual class, column = predicted class; FN costs 10, FP costs 1.
loss <- matrix(c(0, 10, 1, 0), nrow = 2,
               dimnames = list(c("0", "1"), c("0", "1")))
fit <- rpart(isLoanDefault ~ ., data = resampled, method = "class",
             parms = list(loss = loss),
             control = rpart.control(cp = 0.001, xval = 10))
# Prespecified complexity setting, retained from the original example.
# The rpart CV table is diagnostic; cp was not selected by CV in this workflow.
printcp(fit)
pruned <- prune(fit, cp = 0.002)
if (nrow(pruned$frame) > 1) {
  plot(pruned, uniform = TRUE)
  text(pruned, use.n = TRUE, cex = 0.6)
} else {
  message("Pruned model contains a root node only.")
}
```

## Evaluate once on the held-out observations
```{r evaluate}
predicted <- predict(pruned, newdata = test, type = "class")
stopifnot(!anyNA(predicted))
metrics(test$isLoanDefault, predicted)
metrics(test$isLoanDefault, rep("0", nrow(test)))
```
The 2:1 sampling changes class prevalence. Tree probabilities should not be interpreted as calibrated population default probabilities. The assumed 10:1 loss is illustrative; no operational benefit has been established. Training medians are fitted before rpart's internal CV, so those CV scores are not fully fold-isolated. The untouched test split is the final performance check.
