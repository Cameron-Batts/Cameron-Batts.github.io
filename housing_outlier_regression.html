Housing Regression Diagnostics and Price Sensitivity

Cameron Batts

Problem

Investigate repeated sale prices, model assumptions and sensitivity to model-based target replacement.

Approach

Inspect the provided pre/post-2009 files, fit a fixed 15-term regression specification, compare diagnostic plots and retain raw targets separately from an optional replacement scenario.

Reported results

Data checks found 1,933 earlier and 986 later records, each with 82 columns including an exported row index. Thirty later records share the exact sale price $142,769.70, compared with zero earlier records. They span ten neighborhoods, including nine Gilbert and four NAmes observations.

Limitations and corrections

Repeated prices, density peaks and residual patterns do not establish fraud. The original workflow replaced flagged targets with model predictions plus 1% noise; smoother residuals after that operation do not validate recovered prices or independent predictive accuracy. No held-out evaluation was reported. Existing images and PDF contain historical wording and interpretations that predate this correction.

## Fit and inspect the observed data
```{r observed-models}
model_formula <- SalePrice ~ OverallQual + GrLivArea + GarageCars + GarageArea +
  TotalBsmtSF + FullBath + YearBuilt + YearRemodAdd + Fireplaces + LotArea +
  BsmtFinSF1 + KitchenQual + Neighborhood + ExterQual + X1stFlrSF
before_model <- lm(model_formula, data = before, na.action = na.exclude)
after_model <- lm(model_formula, data = after, na.action = na.exclude)
summary(before_model)
summary(after_model)
autoplot(after_model)
ggplot(after, aes(SalePrice)) + geom_density() + facet_wrap(~ Neighborhood, scales = "free_y")
```

## Optional scenario: model-based replacement
Repeated sale prices and residual patterns do not establish fraud. This scenario constructs alternative targets to examine sensitivity; it does not recover verified transaction values. Raw data remain untouched.

```{r scenario}
# Align categorical levels to the training model; unknown levels become NA.
scenario_inputs <- after[flagged, , drop = FALSE]
for (v in names(before_model$xlevels)) {
  scenario_inputs[[v]] <- factor(scenario_inputs[[v]], levels = before_model$xlevels[[v]])
}
scenario_predictions <- predict(before_model, newdata = scenario_inputs)
replaceable <- which(is.finite(scenario_predictions) & scenario_predictions > 0)
set.seed(123)
scenario <- after
scenario$SalePrice[flagged[replaceable]] <- scenario_predictions[replaceable] +
  rnorm(length(replaceable), sd = 0.01 * scenario_predictions[replaceable])
cat("Scenario replacements:", length(replaceable), "of", length(flagged), "flagged rows\n")
scenario_model <- lm(model_formula, data = scenario, na.action = na.exclude)
summary(scenario_model)
autoplot(scenario_model)
```
Improved residuals after replacing targets with model predictions are partly expected by construction. They do not demonstrate improved prediction on independent, verified sales. Compare against held-out untouched transactions before making predictive claims. Complete-case fitting can change sample composition across periods.
