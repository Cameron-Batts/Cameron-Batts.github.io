NYC Flight Delays and Weather: Join Coverage and EDA

Cameron Batts

Problem

Explore departure-delay distributions and weather associations while documenting unmatched and missing records.

Approach

Validate unique airport-hour weather keys, retain all flights in a left join, and explicitly reproduce the original weather-matched population. Compare weather plots within the original delay-over-100-minute subset.

Verified findings

Independent checks using the Python nycflights13 data copy reproduced 336,776 flights and 26,115 weather records. The join matched 335,220 flights and left 1,556 unmatched. Among matched flights, 8,227 had missing departure delays; the observed mean was 12.635 minutes, median −2 minutes and 75th percentile 11 minutes. The severe-delay subset contains 13,287 flights.

Limitations

The historical inner join omitted flights without matching weather. Missing departure delay is a cancellation proxy, not independently confirmed status here. Weather plots conditioned on delays over 100 minutes cannot identify general delay drivers or establish operational causes. No predictive model or ranked weather importance was estimated.

Data

Data are supplied by the nycflights13 R package. The independent check used the packaged Python copy for the same 2013 data; revised R code has not been executed.

Verification

Counts and relevant numerical findings were checked independently in Python. R is unavailable here, so revised R code was reviewed but not parsed, executed or rendered. Historical images are retained separately from the revised workflow.

```{r data}
library(dplyr)
library(ggplot2)
library(nycflights13)
f <- nycflights13::flights
w <- nycflights13::weather
stopifnot(!anyDuplicated(w[c("origin", "time_hour")]))
w$weather_matched <- TRUE
joined <- left_join(f, w, by = c("origin", "time_hour"), suffix = c("", "_weather"))
stopifnot(nrow(joined) == nrow(f))
cat("Original flights:", nrow(f), "\n")
cat("Unmatched weather rows:", sum(is.na(joined$weather_matched)), "\n")
# Reproduce the original inner-join population explicitly.
matched <- filter(joined, !is.na(weather_matched))
summary(matched$dep_delay)
cat("Missing departure delay:", sum(is.na(matched$dep_delay)), "\n")
# Missing departure delay is used as a proxy, not independently verified cancellation status.
matched %>% group_by(origin) %>% summarise(
  flights = n(), missing_departure = sum(is.na(dep_delay)),
  mean_delay = mean(dep_delay, na.rm = TRUE), .groups = "drop")
```

## Delay distribution and restricted weather comparisons
```{r plots}
ggplot(matched, aes(dep_delay)) + geom_histogram(binwidth = 15, na.rm = TRUE) +
  labs(x = "Departure delay (minutes)", title = "Weather-matched flights")
severe <- filter(matched, !is.na(dep_delay), dep_delay > 100)
cat("Severe-delay rows:", nrow(severe), "\n")
for (v in c("temp", "dewp", "humid", "wind_speed", "wind_gust", "precip", "pressure", "visib")) {
  print(ggplot(severe, aes(x = .data[[v]], y = dep_delay, color = origin)) +
          geom_point(alpha = 0.15, na.rm = TRUE) +
          geom_smooth(method = "lm", se = FALSE, na.rm = TRUE) +
          labs(title = paste("Delays over 100 minutes vs", v), y = "Delay (minutes)"))
}
```
A pattern conditional on delays over 100 minutes does not estimate the probability of delay across all flights. Weak scatterplot trends do not demonstrate that operational factors caused the delays. Wind direction is circular and is omitted from straight-line trend fitting. Missing gust readings and extreme weather values require quality review before modeling.
