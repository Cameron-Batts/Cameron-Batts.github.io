Portfolio Volatility and Risk Model Comparison

Cameron Batts

Compare Gaussian GARCH specifications, one-day VaR exceedances, and approximate capital reserves across forecast horizons.

Scope

Results describe the supplied historical snapshot or a stated simulation. Model fit and scenario estimates are not evidence of performance on new observations. See the project README for the execution record and limitations.

tickers <- c("VTI", "VEA", "VWO", "BND", "VNQ", "GLD", "QQQ")

# Portfolio weight on each ticker, matching the order above
weights <- c(0.35, 0.15, 0.10, 0.15, 0.10, 0.05, 0.10)

# Confirm weights sum to one

# Total portfolio market value, used to convert return-based risk measures

date_end   <- "2025-03-15"        # pulled past 30 trading days into 2025 as a buffer

for (i in 1:ntickers) {
  # Load adjusted price history for the requested ticker

                    from = date_start, to = date_end)

  if (i == 1) {
    data <- ret                              # first ticker seeds the data object
  } else {
    data <- merge(data, ret)                 # later tickers are joined on by date
  }
}

# Backtest the 1-day 95% VaR over the test sample with a daily refit,
# moving window equal in length to the training sample.
# ugarchroll's as.data.frame() output stores the realized return and the
# 5% VaR forecast; a violation is a day the realized return fell below VaR
count_violations <- function(spec) {
  roll <- ugarchroll(
    spec, data = full.logret,
    n.start       = n.train,
    refit.every   = 1,
    refit.window  = "moving",
    calculate.VaR = TRUE,
    VaR.alpha     = 0.05,
    solver        = "hybrid"
  )
  df <- as.data.frame(roll)
  # column names from ugarchroll: "Realized" and "alpha(5%)" hold the
  # realized return and the VaR forecast at the 5% tail
  sum(df$Realized < df[["alpha(5%)"]])
}

# Uses ugarchforecast (not simulation) to get the h-day mean and variance
# using summed forecast variances as an approximation for multi-day risk.
# This avoids the instability that came from bootstrap-resampling fat-tailed
# residuals under a highly persistent GARCH process, which was producing
# NaNs and dollar losses larger than the portfolio itself.
forecast_cache <- new.env(parent = emptyenv())
rolling_mean_ES <- function(spec, horizon, confidence) {
  alpha   <- 1 - confidence
  z.alpha <- qnorm(alpha)

  starts <- seq(1, n.test, by = horizon)
  starts <- starts[starts + horizon - 1 <= n.test]  # keep only full windows

  es.vals <- numeric(length(starts))
  for (j in seq_along(starts)) {
    end.idx       <- n.train + starts[j] - 1          # last obs in this expanding window
    logret_window <- full.logret[1:end.idx]

    key <- paste(digest::digest(spec), end.idx, horizon, sep = "-")
    if (!exists(key, envir = forecast_cache, inherits = FALSE)) {
      fit <- ugarchfit(spec, data = logret_window, solver = "hybrid")
      stopifnot(convergence(fit) == 0)
      fc <- ugarchforecast(fit, n.ahead = horizon)
      assign(key, c(mu = sum(as.numeric(fitted(fc))),
                    sd = sqrt(sum(as.numeric(sigma(fc))^2))), envir = forecast_cache)
    }
    cached <- get(key, envir = forecast_cache)
    mu.h <- cached[["mu"]]
    sd.h <- cached[["sd"]]

    # Closed-form Normal ES: -(mean - sd * dnorm(z_alpha)/alpha), in return terms
    es.return  <- -(mu.h - sd.h * dnorm(z.alpha) / alpha)
    es.vals[j] <- portf.value * es.return
  }
  mean(es.vals, na.rm = TRUE)
}

    results[i, (m) := rolling_mean_ES(model.specs[[m]], h, conf)]
  }
}

Interpretation limits

Multi-day reserves use an approximation based on summed conditional forecast variances. Future GARCH returns are not jointly Gaussian merely because one-step innovations are Gaussian. AR mean dynamics can also induce cross-period covariance. A short VaR exceedance check does not validate expected shortfall.
