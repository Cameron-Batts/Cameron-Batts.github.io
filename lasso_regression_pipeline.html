LASSO Feature Selection and Regression Pipelines

Cameron Batts

Problem

Compare LASSO sparsity with ordinary least squares on a controlled synthetic regression problem.

Approach

Generate 1,000 observations, 100 predictors and 10 informative variables with noise=0.005 and random_state=42. Standardize inside a pipeline; search 50 alpha values from 0.0001 to 0.01 with two-fold cross-validation. The default regression scoring is R-squared.

Reported results

The rerun selected the same 10 informative predictor indices, while ordinary least squares retained 100 nonzero coefficients. This demonstrates sparsity in a deliberately low-noise simulation. It does not establish superior held-out prediction or prove that ordinary least squares overfit.

Evaluation limits

No independent test set, forecast error comparison, uncertainty estimate or noise-sensitivity analysis was reported. Pipeline coefficients are on standardized predictor scales and should be converted back before direct comparison with generating coefficients. No trained model file is bundled.

Data

Data is generated by scikit-learn; no external dataset is required.

Verification

All 13 code cells executed sequentially on October 22, 2026 in Python 3.12.14 with NumPy 2.3.5 and scikit-learn 1.8.0. The selected indices exactly matched all ten generating indices; ordinary least squares retained 100 nonzero coefficients. All 50 two-fold CV candidate scores were finite. Selected alpha: 0.0011513953993264468. Best mean CV R-squared: 0.9999999979. This is a deliberately low-noise simulation with no independent held-out evaluation. Jupyter rendering and a separate clean-environment reinstall were not tested.

import numpy as np

from sklearn.datasets import make_regression
from sklearn.linear_model import (
    Lasso,
    LinearRegression
)
from sklearn.model_selection import GridSearchCV
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

Let's simulate some data for a regression problem.

Python code
n = 1000  # number of observations in the data
p = 100   # number of predictors in the data
k = 10    # number of relevant predictors in the data
Python code
X, y, coef = make_regression(n_samples=n,
                             n_features=p,
                             n_informative=k,
                             noise=0.005,  # add a little gaussian noise to the data
                             coef=True,
                             random_state=42)

Keep in mind that *we* generate the data here, therefore we know the "truth" about the data generating process: only 10 predictors are relevant out of the $p = 100$ predictors available in the data.

We would expect that given a sample of $n = 1000$ data points from this data generating process, a LASSO model will be able to select exactly 10 predictors and discard the remaining ones (i.e. set their $\widehat{\beta}$ estimates to 0).

Let's verify empirically whether this is in fact the case.

Python code
lasso_pipeline =  make_pipeline(StandardScaler(), 
    Lasso())

Here we create a grid of 50 (by default) equally spaced (in the log scale) candidate values for the regularization parameter $\alpha$.

Python code
alpha_candidates = np.logspace(-4.0, -2.0)
Python code
print(len(alpha_candidates))
50
Python code
alpha_search = GridSearchCV(lasso_pipeline,
             {'lasso__alpha': alpha_candidates},
             cv=2).fit(X, y)

Here we count how many of the model coefficients for the best LASSO model (i.e. the one corresponding to the optimal value of $\alpha$ selected via cross-validation) are non-zero.
